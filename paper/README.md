# paper/

The ICML 2027 paper. Target deadline: Jan 14, 2027.

## Build

```
cd paper
make PYTHON=~/miniconda3/envs/dem/bin/python     # tables, then PDF
make plots PYTHON=<a python with matplotlib>     # figures
```

`make` runs `../scripts/make_tables.py` first, then builds `main.pdf`. It uses
`latexmk` if present, else `pdflatex` + `bibtex`, else `tectonic`. With none of
them it stops with an error.

On Adi's Mac (checked Nov 26): no `pdflatex` or `latexmk`. `tectonic` 0.17.0
is installed with Homebrew (`brew install tectonic`) and builds the PDF. It
downloads TeX packages on first run, so the first build needs the internet.

## Style files

ICML 2027 has not published its author kit yet
(`https://media.icml.cc/Conferences/ICML2027/Styles/icml2027.zip` returns 404 on
Nov 26, 2026). The files here are the **ICML 2026** kit
(`icml2026.sty`, `icml2026.bst`, `fancyhdr.sty`, `algorithm.sty`,
`algorithmic.sty`). Swap in the 2027 kit when it appears and rename the two
`icml2026` lines in `main.tex`.

Known quirk: under tectonic (XeTeX) the running head prints "Title Suppressed
Due to Excessive Size". The official ICML example does the same under
tectonic, so this comes from the engine, not our title. Check with pdflatex
(for example on Overleaf) before submission.

## Layout

| Path | What |
|---|---|
| `main.tex` | Preamble, title, authors, section includes |
| `sections/*.tex` | One file per section. `abstract.tex` is a DRAFT placeholder |
| `tables/*.tex` | Generated by `scripts/make_tables.py`. Do not edit by hand |
| `figures/fig1.tex` | Figure 1 overview, TikZ (draft) |
| `figures/*.pdf, *.png` | Generated by `scripts/make_plots.py` |
| `refs.bib` | References |

## Generated tables

`scripts/make_tables.py` reads every `results/*.csv` and writes:

- `tables/agent_summary.tex`: success, seconds, LLM calls, tokens and cost per condition
- `tables/format_success.tex`: success per command format (and per split, if a `split` column exists)
- `tables/checkpoint_success.tex`: success per training step (needs `checkpoint_step`)
- `tables/per_task.tex`: success per task and condition
- `../results/tables.md`: the same tables in markdown, plus the source files and commits

Success is shown as a percentage with a Wilson 95% interval and the episode
count. With no CSVs every table says "No results yet". No number is typed by hand.

## Generated figures

`scripts/make_plots.py --train-dir <dir of training CSVs>` writes
`loss_curves`, `success_vs_step`, `success_by_format` and
`success_vs_point_error` as PDF and PNG to `figures/`. Any figure with no data is
skipped. It needs matplotlib, which the `dem` env does not have.
