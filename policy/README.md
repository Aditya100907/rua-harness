# policy/

Adi's side: data loader for the RoboCasa demos, DEM training on Bouchet, and the evaluation script.

- `scripted.py`: scripted baseline that reads simulator ground truth (the "perfect command" oracle). See `docs/testsets.md`.
- `testsets.py`: held-out test sets (look-alike distractors, held-out kitchens, unseen names). See `docs/testsets.md`.
